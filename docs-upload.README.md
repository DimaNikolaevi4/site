### Как залита

Из-за размера (~3.4 ГБ) папка передавалась не одним архивом, а партиями (несколько ZIP с подмножествами кодов либо `rsync`/SCP). Финальная сверка — по `docs_structure.txt`: 799 файлов в `/docs/obrazovanie/`.

### Что сделано в проекте после заливки

1. Все 43 ссылки на `sit-salsk.ru/wp-content/uploads/2024/11/15.01.05_РП_*` в `src/content/pages/svedenija/education/index.md` остаются последним отрезком, который нужно перевести скриптом `scripts/rewrite-doc-urls.mjs` (см. ниже про коррекцию пути).
2. На странице `/svedenija/education/` отсутствуют локальные `/assets/uploads/obrazovanie/…` ссылки — раздел сразу собирался под URL хостинга.

> ⚠️ **Важно про `scripts/rewrite-doc-urls.mjs`:** скрипт исторически собирал URL «плоско» — `…/docs/<имя>`. Реальная структура — **с подпапками** (`/docs/obrazovanie/<имя>`). Перед следующим запуском надо поправить `NEW_BASE` или добавить логику маршрутизации по подпапке (по коду специальности → `obrazovanie/`).

## Контрольный спот-чек после деплоя

Минимальный набор `curl -I` для подтверждения, что все 9 подпапок живы:

```bash
DOMAIN="https://xn----8sbwke6acce8h.xn--p1ai/docs"
for u in \
  "$DOMAIN/dokumenty/Изменения-в-устав-обложка-2025.pdf" \
  "$DOMAIN/vsoko/план-график-ВСОКО_2022-2023.pdf" \
  "$DOMAIN/struktura/<любой-файл>.pdf" \
  "$DOMAIN/pedagog/<любой-файл>.pdf" \
  "$DOMAIN/priemnaya-kampaniya-2026/<любой-файл>.pdf" \
  "$DOMAIN/mezhdunarodnoe/<любой-файл>.pdf" \
  "$DOMAIN/podacha-elektronnaya-pochta/<любой-бланк>.docx" \
  "$DOMAIN/finance/2026/Государственное-задание-на-2026-2028-гг.-ГБПОУ-РО-СИТ.pdf" \
  "$DOMAIN/obrazovanie/15.01.05_РП_ОП.01-Основы-инженерной-графики.pdf" ; do
  printf "%s  " "$(curl -sI -L --max-time 15 -o /dev/null -w '%{http_code}' "$u")"; echo "$u"
done
```

Ожидаем `200` на каждой строке. Голые папки (`/docs/<dir>/`) возвращают `403` — это норма (директорий-листинг отключён).
