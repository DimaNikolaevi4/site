### Структура архива

ZIP собран **без префикса** — каталог `finance/` лежит прямо в корне архива. При распаковке внутри `docs/` получится ровно та структура, которая нужна на хостинге:

```
docs-upload-finance.zip
└── finance/
    ├── 2020/  (17 PDF)
    ├── 2021/  (12 PDF)
    ├── 2022/  (14 PDF)
    ├── 2023/  (14 PDF)
    ├── 2024/  (12 PDF)
    ├── 2025/  (12 PDF)
    └── 2026/  ( 2 PDF)
```

> Имена файлов сохранены **бит-в-бит** (включая русские буквы и точки). Архив создан без сжатия (`-0`), так как PDF уже пожаты — пересжатие даст менее процента выигрыша при значительной потере времени.

### Порядок действий на хостинге

1. Зайти на хостинг по SSH/FTP, перейти в корень сайта (`~/sit-saljsk.rf/public_html/` или эквивалент).
2. Залить `docs-upload-finance.zip` в `docs/` (~247 МБ — лучше через SSH/SCP, чтобы соединение FTP не разорвалось).
3. На сервере распаковать и удалить архив:
   ```bash
   cd docs && unzip docs-upload-finance.zip && rm docs-upload-finance.zip
   ```
4. Проверить права (файлы `644`, папки `755`):
   ```bash
   find finance -type d -exec chmod 755 {} \;
   find finance -type f -exec chmod 644 {} \;
   ```
5. Спот-чек 2–3 случайных файла из разных годов:
   ```bash
   curl -I "https://сит-сальск.рф/docs/finance/2026/Государственное-задание-на-2026-2028-гг.-ГБПОУ-РО-СИТ.pdf"
   curl -I "https://сит-сальск.рф/docs/finance/2024/<любой-файл>.pdf"
   curl -I "https://сит-сальск.рф/docs/finance/2020/<любой-файл>.pdf"
   ```
   Ожидаем `HTTP/2 200` и `Content-Type: application/pdf`.

### Что делать в проекте после успешной заливки

После подтверждённой заливки (Ф5.1–Ф5.4) — выполнить миграцию ссылок (Ф5.5–Ф5.10 в разделе 7.0 чеклиста):

1. Заменить **83 ссылки** в `src/content/pages/svedenija/finance/index.md`:
   ```bash
   sed -i 's|/assets/uploads/finance/|https://xn----8sbwke6acce8h.xn--p1ai/docs/finance/|g' \
     src/content/pages/svedenija/finance/index.md
   ```
2. Пересобрать и проверить, что в HTML нет утечек:
   ```bash
   rm -rf public/ && npm run build
   rg "/assets/uploads/finance/" public/ -g "*.html" -l   # должно быть 0
   ```
3. Удалить локальную папку:
   ```bash
   rm -rf src/assets/uploads/finance/
   ```
4. Обновить шапку 7.0 в `CHECKLIST.md` (перенести `finance/` из «к миграции» в «уже перенесены»).
5. Закоммитить изменения; запустить `deploy.sh` на хостинге.
6. Финальная проверка: открыть `https://сит-сальск.рф/svedenija/finance/`, проверить 2–3 PDF из разных годов.
