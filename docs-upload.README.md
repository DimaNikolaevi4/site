## 2. Структура архива

ZIP собран **без префикса** — то есть подпапки лежат в корне архива и при распаковке получится ровно та структура, которая должна появиться на хостинге внутри папки `docs/`:

```
docs-upload.zip
├── dokumenty/
│   ├── … 304 файла (PDF / DOC / DOCX / ZIP с электронными подписями)
│   └── anti-corruption/                ← вложенная подпапка с локальными актами
├── vsoko/
│   └── … 90 файлов (56 PDF + 33 ZIP с ЭП + 1 JPG)
├── struktura/
│   └── … 33 файла (положения с эл. подписями, орг. структура и т.д.)
├── pedagog/
│   └── … 16 файлов
├── priemnaya-kampaniya-2026/
│   └── … 15 файлов (правила приёма, положения, КЦП и т.д.)
├── mezhdunarodnoe/
│   └── … 9 файлов
└── podacha-elektronnaya-pochta/
    └── … 6 файлов (бланки заявлений по 6 специальностям/профессиям)
```

> Имена файлов и подпапок сохранены **бит-в-бит** (включая русские имена и спецсимволы) — на хостинге Beget важно, чтобы кодировка имён осталась UTF-8. Архив создан без сжатия (`-0`), потому что 99% содержимого — это уже сжатые форматы (PDF/DOC/DOCX/ZIP), и пересжатие давало бы выигрыш менее процента при значительной потере времени.

## 3. Куда заливать на хостинге (Beget)

Боевой путь на хостинге — папка **`docs/`** в корне сайта, рядом с обычными HTML-файлами Eleventy:

```
сит-сальск.рф/                         ← document root на Beget
├── index.html                         ← собранные страницы Eleventy
├── assets/
├── …
└── docs/                              ← СЮДА распаковать архив
    ├── dokumenty/
    ├── vsoko/
    ├── struktura/
    ├── pedagog/
    ├── priemnaya-kampaniya-2026/
    ├── mezhdunarodnoe/
    └── podacha-elektronnaya-pochta/
```

**Рекомендуемый порядок действий:**

1. Зайти на хостинг по SSH/FTP, перейти в корень сайта.
2. Создать папку `docs/`, если её ещё нет.
3. Залить `docs-upload.zip` целиком в `docs/` (~423 МБ — лучше через SSH/SCP, чтобы не разрывалось соединение FTP).
4. На сервере распаковать: `cd docs && unzip docs-upload.zip && rm docs-upload.zip`.
5. Проверить права: файлы должны быть доступны на чтение веб-серверу (обычно `644`, папки `755`).
6. Спот-чек 2–3 случайных файла из разных подпапок:
   ```
   curl -I https://сит-сальск.рф/docs/dokumenty/ustav.pdf
   curl -I https://сит-сальск.рф/docs/vsoko/<любой-файл>.pdf
   curl -I https://сит-сальск.рф/docs/struktura/<любой-файл>.pdf
   ```
   Ожидаем `HTTP/2 200` и корректный `Content-Type` (`application/pdf`, `application/zip`, …).

## 4. Что делать после успешной заливки

Когда заливка подтверждена, в проекте Eleventy выполняется **универсальная процедура переноса** из таблицы 7.0 (шаги 4–9) — отдельно по каждой из 7 подпапок:

1. найти все ссылки `/assets/uploads/<folder>/` в `src/`;
2. заменить их на `{{ site.docsBaseUrl }}<folder>/...` (либо через будущий фильтр `| docs`);
3. собрать проект, проверить страницы;
4. удалить `src/assets/uploads/<folder>/` из проекта (`git rm -r`);
5. закоммитить и проставить ✅ в карте 7.0 и в соответствующем подразделе 7.X.

После переноса всех 7 подпапок — добавить 301-редиректы `/assets/uploads/*` → `/docs/*` в `.htaccess` хостинга (шаг П6).

Эти подпапки остаются в `src/assets/uploads/` и заливать их на хостинг **не нужно** — они подгружаются прямо из проекта при локальной разработке и сборке:

**Итого «остаётся в проекте»:** 56 изображений, ~1.8 МБ.
