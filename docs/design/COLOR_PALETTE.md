# Цветовая карта сайта СИТ

**Источник истины:** src/styles/main.css
**Ветка:** site-v2
**Назначение:** единая справка по цветам интерфейса и визуальным токенам сайта.

> При изменении палитры сначала обновляйте CSS-переменные в src/styles/main.css, затем синхронизируйте этот документ.

## Шрифты

| Назначение | Значение |
|---|---|
| Основной текст | Open Sans |
| Заголовки | Raleway |
| Навигация | Poppins |

## Футер

### Светлая тема

- Фон: белый и производные от --accent-color через color-mix
- Основной текст: #455048
- Усиленный текст: #1f2a23
- Приглушённый текст: #6b7a72
- Иконки и акцент: --accent-color

### Тёмная тема

- Фон: #1b2620 и #243029
- Основной текст: rgba(255, 255, 255, 0.78)
- Приглушённый текст: rgba(255, 255, 255, 0.55)
- Фон карточек: rgba(255, 255, 255, 0.04)
- Фон иконок: rgba(95, 207, 128, 0.15)
