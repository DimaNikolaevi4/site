# Спецификация Front Matter для сайта sit-salsk.ru

Этот документ описывает обязательную структуру метаданных (Front Matter) для всех Markdown-файлов проекта. 
Front Matter располагается в самом начале файла между тройными дефисами `---` и используется движком Eleventy для генерации страниц, меню, хлебных крошек и поиска.

## Общие правила

1. **Формат:** YAML.
2. **Расположение:** Первые строки файла `.md`.
3. **Кодировка:** UTF-8.
4. **Обязательные поля:** `title`, `layout`, `permalink`.
5. **Язык:** Все текстовые значения на русском языке (кроме технических ключей).

---

## 1. Шаблон: Стандартная статья (Post/Article)

Используется для новостных заметок, истических справок, описания достопримечательностей.

```yaml
---
title: "Заголовок статьи (H1)"
description: "Краткое описание для SEO (meta description), 150-160 символов."
date: 2024-01-15 # Дата публикации (ГГГГ-ММ-ДД)
lastModified: 2024-01-20 # Дата последнего изменения (опционально)
author: "Администрация" # Или конкретное имя
category: "history" # Слаг категории (должен совпадать с папкой или таксономией)
tags:
  - "Сальск"
  - "история"
  - "архив"
image: "/assets/images/posts/nazvanie-foto.jpg" # Главное изображение (опционально)
imageAlt: "Описание изображения для доступности"
layout: "layouts/post.njk" # Используемый шаблон
permalink: "/history/statiya-o-gorode/" # ЧПУ ссылка (обязательно со слэшем в конце)
draft: false # true, если черновик
searchable: true # Исключить из поиска, если false
---
```

### Пояснения к полям:
- **`category`**: Должен соответствовать одному из основных разделов сайта (`history`, `culture`, `news`, `people`, `places`).
- **`tags`**: Массив ключевых слов для облака тегов и внутреннего поиска.
- **`permalink`**: Структура должна быть `/категория/название-статьи/`.

## 2. Шаблон: Страница раздела (Section/Taxonomy)

Используется для страниц категорий, рубрик или списков материалов (например, `/history/`).

```yaml
---
title: "Название раздела"
description: "Описание раздела для SEO."
sectionId: "history" # Уникальный идентификатор раздела
icon: "book-open" # Иконка раздела (из библиотеки иконок)
order: 2 # Порядок сортировки в главном меню
layout: "layouts/section.njk" # Шаблон списка
permalink: "/history/"
children:
  - "/history/statiya-1/"
  - "/history/statiya-2/"
# Поле children может заполняться автоматически через коллекции Eleventy, 
# но вручную указывается для статических разделов
---
```

## 3. Шаблон: Техническая страница (Static Page)

Используется для страниц "О проекте", "Контакты", "Политика конфиденциальности".

```yaml
---
title: "Контакты"
description: "Как связаться с редакцией сайта."
layout: "layouts/page.njk" # Базовый шаблон без боковой панели
permalink: "/contacts/"
showInMenu: false # Не показывать в главном меню (если нужно в футере)
menuLocation: "footer" # Расположение ссылки (header, footer, none)
---
```

## 4. Шаблон: Главная страница (Home)

Уникальный шаблон для `index.md` в корне `src/`.

```yaml
---
title: "Сальск: История, Культура, Люди | Официальный информационный портал"
description: "Все о городе Сальске: история основания, новости культуры, биографии земляков, фотогалерея достопримечательностей."
layout: "layouts/home.njk"
permalink: "/"
featuredPosts:
  - "/news/novost-1/"
  - "/history/yubilej-goroda/"
# Список ссылок на статьи для блока "Рекомендуем"
---
```

## Справочник категорий (Category Slugs)

Для обеспечения единообразия используйте следующие слагы для поля `category`:

| Категория | Слаг | Описание |
|-----------|------|----------|
| История | `history` | Статьи об истории города и района |
| Культура | `culture` | Театры, музеи, мероприятия |
| Новости | `news` | Актуальные события |
| Люди | `people` | Биографии, интервью |
| Места | `places` | Достопримечательности, карты |
| Экономика | `economy` | Бизнес, предприятия |

## Примеры использования в контенте

### Пример 1: Новость
```markdown
---
title: "В Сальске прошел фестиваль народного творчества"
description: "Более 50 коллективов приняли участие в ежегодном фестивале."
date: 2024-05-10
category: "culture"
tags: ["фестиваль", "творчество", "событие"]
layout: "layouts/post.njk"
permalink: "/culture/festival-2024/"
---

Здесь начинается текст новости...
```

### Пример 2: Историческая справка
```markdown
---
title: "Основание станции Торговая"
description: "Исторический очерк о появлении железнодорожной станции."
date: 2023-11-01
category: "history"
tags: ["железная дорога", "XIX век", "основание"]
image: "/assets/images/history/station-old.jpg"
layout: "layouts/post.njk"
permalink: "/history/osnovanie-stancii/"
---

Текст статьи...
```

## Валидация

Перед коммитом убедитесь, что:
1. Все даты в формате `YYYY-MM-DD`.
2. `permalink` начинается и заканчивается слэшем `/`.
3. `layout` указывает на существующий файл в папке `src/_includes/layouts/`.
4. Отсутствуют дублирующиеся `permalink`.
