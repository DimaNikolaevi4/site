# Реестр внешних источников текстов V2

Дата формирования: 2026-09-21  
Ветка: `site-v2`  
Связанный пункт чеклиста: 2.4.2 — «Для внешних текстов указать официальный источник или разрешение». 

## Как пользоваться реестром

Этот файл — рабочий чеклист для анализа внешних страниц, на которые ссылается контент V2. Наличие ссылки фиксирует источник или контекст, но **не является разрешением на воспроизведение текста**. Для каждого материала нужно отдельно определить:

- [ ] источник официальный или подтверждён автор текста;
- [ ] в V2 используется только ссылка/факт либо воспроизводится чужой текст;
- [ ] есть основание публикации: собственное авторство, разрешение, лицензия или официальный нормативный источник;
- [ ] дата, название организации и реквизиты актуальны;
- [ ] принято действие: оставить с атрибуцией, запросить разрешение, переписать своими словами или удалить.

Статус всех строк на момент формирования: `REVIEW_REQUIRED`. Категория ниже предварительная и не устанавливает авторство.

После гибридной классификации подробная матрица решений вынесена в [`EXTERNAL_TEXT_PERMISSION_CHECKLIST.md`](./EXTERNAL_TEXT_PERMISSION_CHECKLIST.md). Материал `src/content/news/2026-02-13-pobeda-za-nami.md` классифицирован как `OFFICIAL_REFERENCE / FACTS_ONLY`: ссылка на портал ONF сохранена, а дословное совпадение с текущей страницей не выявлено. Пункт 2.4.2 закрывается с оговоркой, что реестр не является юридическим заключением.
