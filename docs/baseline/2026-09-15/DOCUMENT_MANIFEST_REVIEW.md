Список из манифеста сопоставлен с файлами ветки по пути `src/<путь из манифеста>` и размеру файла:

В манифесте также есть 2 графические записи (`docs/kontrakt/kontrakt.jpg` и `docs/kontrakt/работа для каждого своего.png`). Они не относятся к проверяемому набору документов и сохранены без изменения, чтобы не переписывать исторический реестр без отдельного решения.

## Ограничения проверки

Проверка подтверждает полноту списка и совпадение размеров. SHA-256 из манифеста не пересчитывался по содержимому через GitHub API; проверка фактического типа файлов по сигнатуре/содержимому выполняется отдельным пунктом чек-листа.

## Метод

1. Получен рекурсивный Git tree ветки `site-v2` через GitHub API.
2. Для каждой записи манифеста проверен файл `src/<путь>`.
3. Для всех файлов с расширениями PDF/DOC/DOCX/XLSX в `src/assets/uploads/` и `src/docs/` проверено обратное наличие в манифесте.
4. Размеры из манифеста сопоставлены с размерами blob-файлов.
