# Аудит alt-текстов изображений

Дата проверки: 2026-09-21  
Ветка: site-v2  
Связанный пункт: 2.3 — проверить наличие alt-текста и соответствие alt фактическому изображению.

## Методика

Проверены все основные V2-компоненты, которые выводят img: header, footer, about, hero-related cards, news, popular, sidebar, related и layout-карточки. Для спорных ведомственных и региональных ассетов просмотрены сами исходные изображения, а не только имена файлов. Для фонового hero используется CSS background-image; отдельный alt для CSS-фона не создаётся.

## Результат

- У обычных img в проверенных компонентах есть alt: явный, либо fallback на заголовок карточки/материала.
- Дублирующий логотип в offcanvas-header и декоративный знак в footer имеют пустой alt и aria-hidden=true; это корректное скрытие повторяющейся декоративной графики.
- В footer ранее часть alt описывала целевую организацию ссылки, а не видимый знак. Это исправлено: alt описывает эмблему, герб или пиктограмму, а aria-label ссылки сохраняет доступное имя целевой организации.

## Воспроизводимая проверка после сборки

Для проверки именно сгенерированного каталога public/ добавлен scripts/audit-alt-text.mjs. Скрипт рекурсивно проверяет активные теги <img>, отсутствие/пустой/мусорный alt, выводит файл и строку и исключает HTML-комментарии. Запуск:

~~~bash
npm run build
npm run audit:alt
~~~

Каталог public/ не хранится в ветке, поэтому его итоговые количества появляются в отчёте после запуска сборки и команды аудита. Скрипт и исходный аудит являются проверяемым результатом; право публикации и атрибуция остаются предметом пунктов 2.3.2–2.3.3.
