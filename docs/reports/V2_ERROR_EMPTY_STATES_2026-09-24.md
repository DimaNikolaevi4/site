# V2: проверка error и empty состояний

- Дата проверки: 2026-09-24.
- Ветка: `site-v2`.

Проверены исходные шаблоны и V2-output:

- 404: отдельный блок `error-404` с кодом ошибки, объяснением и действиями.
- Листинги: отдельный блок `no-results` с пояснением и ссылкой на главную.
- `page-full`: отдельный блок `no-results` для пустой коллекции.
- Поиск: отдельный `search-no-results` для пустого результата и отдельное сообщение «Поиск временно недоступен» при ошибке загрузки индекса.

Состояния не маскируются пустым контейнером или обычным успешным шаблоном. Ошибок по проверенным шаблонам не найдено.
