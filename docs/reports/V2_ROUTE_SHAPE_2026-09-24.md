## Результат

После чистой установки (`npm ci --no-audit --no-fund`) выполнена команда
`npm run build:v2`. Сборка Eleventy завершилась успешно. В `public-v2/`
проверено 145 HTML-файлов и 145 уникальных URL:

- корневая страница `public-v2/index.html` публикуется как `/`;
- страница ошибки существует как `/404.html`;
- вложенные `index.html` публикуются как URL каталогов с завершающим `/`;
- ни один URL не содержит `/index.html`;
- дублирующихся HTML-маршрутов нет.

Повторяемые проверки:

- `npm run check:route-shape:v2` — проверяет сгенерированный каталог `public-v2/`;
- `npm run check:route-shape` — проверяет 144 записи baseline-манифеста.

Обе проверки завершились успешно. Для `check:route-shape:v2` добавлен скрипт
`scripts/check-generated-route-shape.mjs`.

## Границы проверки

Проверена форма URL, создаваемая V2-сборкой. HTTP-перенаправления для прямого
запроса `/index.html` или URL без завершающего `/` на сервере Beget требуют
отдельной проверки после тестового деплоя; она остаётся в разделе 11 чек-листа.
