# V2: аудит явных CSS/JS-подключений

- Дата проверки: 2026-09-24.
- Ветка: `site-v2`.
- Проверено: 145 HTML-файлов в `public-v2`.

## Результат

- 142 обычные страницы используют один одинаковый набор из 5 CSS-файлов и 10 JS-файлов, перечисленный в `src/_includes/layouts/base.njk`.
- Для каждого CSS-файла присутствует preload и обычный `noscript` fallback; это две загрузочные стратегии одного ресурса, а не два разных stylesheet-подключения.
- Страница `/search/` добавляет только специализированный `/assets/js/search.js`.
- Служебная `/admin/` подключает только Decap CMS и не входит в обычный сайт.
- Redirect-страница не подключает ассеты, поскольку сразу переадресует пользователя.
- Wildcard-подключений, неявной загрузки CSS/JS и расхождений между обычными страницами не найдено.

Проверены исходные шаблоны `src/_includes`, страницы `src/pages`/`src/content` и сгенерированный V2-output. Набор подключений признан явным и минимальным в пределах текущей архитектуры.
