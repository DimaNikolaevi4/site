# Аудит самостоятельной структуры hero V2

Дата: 2026-09-28  
Ветка: `site-v2`  
Файл: `src/_includes/components/hero.njk`

## Выполнено

- Разметка собрана вокруг собственного пространства имён `site-hero__*`; прежние `page-hero__*` классы сохранены как совместимый слой текущей визуальной системы.
- Сохранены все front matter-контракты: `showHero`, `hero.image`, `hero.alt`, `hero.title`, `hero.subtitle`, `hero.cta`, `rubricTitle`, `title`, `hideRubric`.
- Сохранён режим случайного фонового изображения главной страницы с `sessionStorage`.
- Внешние ссылки получили `rel="noopener noreferrer"`; основной текстовый контент не изменён.
- В компоненте нет строк `mentor-main`, `BootstrapMade` или Mentor-путей.

## Статическая проверка

- присутствуют ровно один `<section>` hero и один `id="page-hero-bg"`;
- сохранены fallback для названия организации, рубрики и изображения;
- CTA выводится только при наличии `url` и `label`;
- на главной остаётся один `h1`, на внутренних страницах `h1` используется для рубрики.

Браузерный прогон и сборка проверяются отдельными пунктами чек-листа.
