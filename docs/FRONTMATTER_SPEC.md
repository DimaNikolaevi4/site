# Спецификация Front Matter для сайта ГБПОУ РО "СИТ"

> 📄 **Файл:** `FRONTMATTER_SPEC.md`  
> 🔄 **Версия:** 1.0  
> 📅 **Создан:** Апрель 2026  
> 🎯 **Проект:** Модернизированное зеркало `https://sit-salsk.ru/` на базе Eleventy + Decap CMS

Этот документ описывает обязательную структуру метаданных (Front Matter) для всех Markdown-файлов проекта.  
Front Matter располагается в самом начале файла между тройными дефисами `---` и используется движком Eleventy для генерации страниц, меню, хлебных крошек, поиска (Lunr.js) и редактора контента (Decap CMS).

---

## Общие правила

1. **Формат:** YAML.
2. **Расположение:** Первые строки файла `.md`.
3. **Кодировка:** UTF-8.
4. **Обязательные поля:** `title`, `layout`, `permalink`.
5. **Язык:** Все текстовые значения на русском языке (кроме технических ключей и слагов).
6. **Структура URL:** `permalink` должен отражать иерархию рубрик, например `/rubric-slug/subrubric-slug/nazvanie-stranicy/`.
7. **Рубрикация:** Каждый материал должен принадлежать хотя бы одной рубрике согласно структуре сайта-донора (см. раздел «Справочник рубрик»).

## 1. Шаблон: Материал (Новость, Документ, Статья)

Используется для всех динамических материалов (новостей, объявлений, документов, страниц подразделов).

```yaml
---
title: "Заголовок материала (H1)"
description: "Краткое описание для SEO (meta description), 150–160 символов."
date: 2026-04-18           # Дата публикации (ГГГГ-ММ-ДД)
lastModified: 2026-04-20    # Дата последнего изменения (опционально, используется для кэширования сборки)
author: "Администрация"      # Автор материала (по умолчанию название организации)
rubric: "1.3"               # Код рубрики согласно SITE_RUBRICS_STRUCTURE.md (обязательно!)
category: "abiturientam"    # Слаг родительской рубрики верхнего уровня (опционально, генерируется из rubric)
tags:
  - "приём"
  - "абитуриенту"
  - "2026"
image: "/assets/images/posts/priem-2026.jpg"   # Главное изображение (опционально)
imageAlt: "Студенты СИТ в аудитории"           # Alt-текст для доступности
layout: "layouts/post.njk"   # Шаблон страницы материала
permalink: "/abiturientam/priemnaya-kampaniya-2026/"  # ЧПУ (генерируется автоматически из title и rubric)
draft: false                 # true — черновик (не публикуется)
searchable: true             # Исключить из индекса Lunr, если false
attachments:                 # Список вложений (опционально)
  - name: "Памятка абитуриента"
    url: "/uploads/pamyatka-2026.pdf"
    size: "1.2 MB"
skipBuildIfOlderThan: 30     # (Опционально) Не пересобирать страницу при деплое, если не менялась >30 дней
---
```

### Пояснения к полям:

| Поле | Обязательное | Назначение |
|------|--------------|------------|
| `title` | ✅ | Заголовок страницы (отображается в `<h1>` и `<title>`) |
| `description` | ✅ | Мета-описание для SEO и соцсетей |
| `date` | ✅ | Дата публикации в формате ISO. Сортировка материалов в списках. |
| `rubric` | ✅ | Код рубрики согласно структуре сайта-донора (например, `"1.3"` для «Приемная кампания 2025»). Используется для построения навигации и фильтрации поиска. |
| `tags` | 🟡 | Массив ключевых слов. Каждый тег становится кликабельной ссылкой `/tags/тег/`. |
| `image` / `imageAlt` | 🟡 | Главное изображение для превью и соцсетей. `alt` обязателен при наличии изображения. |
| `layout` | ✅ | Шаблон из `src/_includes/layouts/`. Для материалов — `post.njk`. |
| `permalink` | ✅ | Уникальный URL страницы. Генерируется по шаблону: `/{category-slug}/{title-slug}/`. |
| `draft` | 🟡 | Если `true`, страница исключается из коллекций Eleventy. |
| `searchable` | 🟡 | Если `false`, материал не попадает в поисковый индекс Lunr. |
| `attachments` | 🟢 | Список файлов для скачивания. Отображается в блоке «Вложения». |
| `skipBuildIfOlderThan` | 🟢 | Для оптимизации сборки (см. раздел 6 в README.md). Пропускает пересборку старых страниц. |

## 2. Шаблон: Страница рубрики / раздела (Section / Taxonomy)

Используется для индексных страниц рубрик (например, `/abiturientam/`, `/vospitanie/`).

```yaml
---
title: "Абитуриентам"
description: "Вся необходимая информация для поступающих в Сальский индустриальный техникум."
sectionId: "abiturientam"       # Уникальный слаг раздела (совпадает с папкой в URL)
rubricCode: "1"                 # Код рубрики верхнего уровня (например, "1")
order: 1                        # Порядок в главном меню
icon: "school"                  # Иконка раздела (опционально, для оформления)
layout: "layouts/listing.njk"   # Шаблон списка материалов
permalink: "/abiturientam/"
showSidebar: true               # Показывать сайдбар (виджеты: поиск, теги, архив)
sidebarWidgets:                 # Список активных виджетов в сайдбаре
  - "search"
  - "rubric-nav"
  - "tags-cloud"
children:                       # Список дочерних подразделов (может заполняться автоматически через коллекции)
  - "/abiturientam/slovo-direktora/"
  - "/abiturientam/specialnosti/"
  - "/abiturientam/priemnaya-kampaniya-2025/"
---
```

### Пояснения:

- **`sectionId`** — используется для связывания материалов с родительской рубрикой через поле `category`.
- **`rubricCode`** — числовой или буквенно-цифровой код рубрики согласно `SITE_RUBRICS_STRUCTURE.md`. Необходим для работы выпадающего списка рубрик и фильтрации поиска.
- **`children`** — может быть сгенерирован автоматически через коллекции Eleventy, но ручное указание полезно для статической генерации меню.

## 3. Шаблон: Статическая страница (О техникуме, Контакты, Политика)

```yaml
---
title: "Контакты"
description: "Адрес, телефон, электронная почта и схема проезда ГБПОУ РО 'СИТ'."
layout: "layouts/page.njk"      # Базовый шаблон без боковой панели
permalink: "/contacts/"
showInMenu: false               # Не показывать в главном меню (можно разместить в футере)
menuLocation: "footer"          # Расположение ссылки: header, footer, none
searchable: true                # Включать ли в поисковый индекс
---
```

## Валидация Front Matter

Перед коммитом убедитесь, что:

1. ✅ Все даты в формате `YYYY-MM-DD`.
2. ✅ `permalink` начинается и заканчивается слэшем `/`.
3. ✅ `layout` указывает на существующий файл в папке `src/_includes/layouts/`.
4. ✅ Поле `rubric` содержит корректный код из справочника.
5. ✅ Отсутствуют дублирующиеся `permalink`.
6. ✅ Для каждого информативного изображения заполнен `imageAlt`.
7. ✅ Поле `title` уникально в пределах своей рубрики.

### Дополнительные правила для Decap CMS:

- При использовании редактора Decap CMS front matter генерируется автоматически на основе `config.yml`.  
  Убедитесь, что в конфигурации CMS правильно настроены коллекции, соответствующие данной спецификации.
- Для новых материалов, создаваемых через CMS, поле `rubric` должно выбираться из предустановленного списка (на основе справочника рубрик).
