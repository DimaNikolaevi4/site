# План миграции контента: HTML → Markdown

## 🎯 Цель
Перенести контент из статических HTML-файлов в `/mirror` в формат Markdown для использования в сборке Eleventy в `/src/content`.

---

## 📋 Почему это важно?

### Преимущества Markdown для нашего проекта:
1. **Читаемость** - контент легко редактировать без знания HTML
2. **Версионность** - чистые диффы в Git, легко отслеживать изменения
3. **Интеграция с Eleventy** - нативная поддержка `.md` файлов
4. **Frontmatter** - метаданные (заголовки, даты, теги) в начале файла
5. **Переиспользование** - один файл контента может использоваться в разных шаблонах
6. **Автоматизация** - легче создавать скрипты для обработки и валидации

### Что теряем при отказе от миграции:
- Ручное редактирование каждого раздела через правку HTML
- Сложность поддержки единого стиля
- Невозможность использовать преимущества шаблонизатора
- Дублирование кода (header, footer в каждом файле)

## 🚀 Процесс миграции

### Шаг 1: Анализ структуры HTML
Для каждого файла определить:
- Заголовок страницы (`<h1>` или `<title>`)
- Метаданные (описание, ключевые слова, дата)
- Основной контент (абзацы, списки, таблицы, изображения)
- Специфические элементы (карточки товаров, формы, галереи)

### Шаг 2: Извлечение чистого контента
Удалить из HTML:
- ✅ Оставить: заголовки, параграфы, списки, таблицы, ссылки, изображения
- ❌ Удалить: `<header>`, `<footer>`, `<nav>`, `<script>`, `<style>`
- ⚠️ Преобразовать: инлайн-стили → классы или удалить

**Примечание:** Миграция ещё не начата (ROADMAP.md строка 310: "Миграция контента | 0%"). Этот документ описывает план будущих действий.

### Шаг 3: Создание Markdown-файла
Формат файла `.md`:

```markdown
---
layout: layouts/base.njk
title: "Название раздела"
description: "Краткое описание для SEO"
date: 2024-01-15
tags: [раздел, категория]
permalink: /path/to/page/
eleventyNavigation:
  key: Section Name
  parent: Main Section
  order: 1
---

# Заголовок раздела

Основной текст раздела...

## Подраздел

- Список элементов
- Еще элемент

[Ссылка](/path)
![Изображение](/images/pic.jpg)
```

### Шаг 4: Обработка специальных элементов

#### Таблицы:
**HTML:**
```html
<table>
  <tr><th>Название</th><th>Цена</th></tr>
  <tr><td>Товар 1</td><td>100₽</td></tr>
</table>
```

**Markdown:**
```markdown
| Название | Цена |
|----------|------|
| Товар 1  | 100₽ |
```

#### Изображения:
**HTML:**
```html
<img src="/images/product.jpg" alt="Описание" class="product-image">
```

**Markdown:**
```markdown
![Описание](/images/product.jpg){: .product-image}
```
Или с использованием shortcode в Eleventy:
```markdown
{% image "/images/product.jpg", "Описание", "product-image" %}
```

#### Ссылки:
**HTML:**
```html
<a href="/catalog/item-1" class="btn">Подробнее</a>
```

**Markdown:**
```markdown
[Подробнее](/catalog/item-1){: .btn}
```

## 🛠️ Инструменты для миграции

### Автоматическая конвертация (рекомендуется):

#### 1. Pandoc - универсальный конвертер
```bash
pandoc input.html -f html -t markdown -o output.md
```

#### 2. Custom Node.js скрипт (будет создан):
Скрипт будет использовать следующие библиотеки:
- `cheerio` или `jsdom` - для парсинга HTML
- `turndown` - для конвертации в Markdown
- `js-yaml` - для генерации frontmatter

**Пример структуры скрипта:**
```javascript
const cheerio = require('cheerio');
const TurndownService = require('turndown');
const fs = require('fs');
const path = require('path');

// Конфигурация
const MIRROR_DIR = './mirror';
const OUTPUT_DIR = './src/content/categories';

// Функция конвертации одного файла
function convertFile(htmlPath, outputPath) {
  const html = fs.readFileSync(htmlPath, 'utf8');
  const $ = cheerio.load(html);
  
  // Извлечение контента из <main>
  const mainContent = $('main').html();
  
  // Конвертация в Markdown
  const turndown = new TurndownService();
  const markdown = turndown.turndown(mainContent);
  
  // Генерация frontmatter
  const title = $('h1').text() || $('title').text();
  const description = $('meta[name="description"]').attr('content') || '';
  
  const frontmatter = `---
layout: layouts/post.njk
title: "${title}"
description: "${description}"
date: ${new Date().toISOString().split('T')[0]}
---

`;
  
  // Запись файла
  fs.writeFileSync(outputPath, frontmatter + markdown);
}

// Пакетная обработка всех файлов
// ... код обхода директории mirror/
```

#### 3. Turndown Service - онлайн или локально
```javascript
const TurndownService = require('turndown');
const turndown = new TurndownService({
  headingStyle: 'atx',
  codeBlockStyle: 'fenced'
});
const markdown = turndown.turndown(htmlString);
```
