Сальский индустриальный техникум (ГБПОУ РО «СИТ») продолжает внедрять передовые образовательные технологии. Команда преподавателей под руководством победителя областного конкурса «Преподаватель года – 2025» Дмитрия Бардакова и его коллеги Наталии Мышанской реализует проект **«Интеллектуальный тьютор на базе открытых языковых моделей для практико-ориентированного обучения в СПО»**.

![Интеллектуальный тьютор на базе ИИ для практико-ориентированного обучения в СПО](/assets/images/news/ai-tyutor.jpg "Интеллектуальный тьютор на базе ИИ")

## О проекте и проблематике

Интеллектуальный тьютор — ИИ-система, предназначенная для автоматизации создания учебного контента и персонализации обучения в системе среднего профессионального образования (СПО, специальность 15.02.14 «Оснащение средств автоматизации»). Проект призван устранить критический дисбаланс между объёмом теоретического материала и ограниченным количеством аудиторных часов, отведённых на практическую отработку навыков.

**Ключевые проблемы СПО, которые решает система:**

- **Перегрузка преподавателей** — до 5–7 часов в неделю тратится на повторяющиеся консультации по одним и тем же темам (основы автоматики, датчики, ПЛК, SCADA-системы)
- **Сложности студентов** — 67 лекций по двум дисциплинам («Измерительные системы» и «Промышленная автоматизация») содержат большой объём специализированной терминологии, которую студентам сложно усваивать самостоятельно
- **Ограниченность аудиторного времени** — недостаточное количество часов для отработки практических компетенций; аудиторное время уходит на теорию
- **Дисбаланс теории и практики** — смещение фокуса на теоретическую подготовку снижает качество практических навыков выпускников

## Техническое решение

Система развертывается на собственном сервере учебного заведения с использованием открытой языковой модели. Это обеспечивает полный контроль над данными, независимость от внешних API и безопасность персональных данных учащихся.

| Компонент | Технология | Описание |
|---|---|---|
| Базовая модель | Qwen2.5-7B-Instruct | 24 млрд параметров, лицензия Apache 2.0, мультиязычность (включая русский язык), контекстное окно на 128 тыс. токенов |
| Метод дообучения | 4-битный QLoRA | Эффективное дообучение при минимальных ресурсах GPU (16–24 ГБ видеопамяти) |
| Платформа инференса | BentoML v1.2+ | Продакшн-сервер с REST API для развертывания модели |
| Интеграция с ЭОС | Moodle 4.x | Плагин для LMS (блок + AJAX API, PHP + JavaScript) |
| Перспектива | ИИ-Монолит | Российская языковая модель (планируемая миграция при появлении) |

## Архитектура и API

Сервис реализован как BentoML-микросервис (service.py) и предоставляет четыре конечных точки REST API для взаимодействия с моделью:

| Эндпоинт | Метод | Назначение | Параметры |
|---|---|---|---|
| /health | GET | Проверка доступности модели | — |
| /generate_summary | POST | Создание структурированного конспекта лекции | lecture_text, max_new_tokens (512), temperature (0,7) |
| /generate_quiz | POST | Создание тестовых вопросов с вариантами ответов | lecture_text, num_questions (5), difficulty (easy/medium/hard) |
| /chat | POST | Диалог с тьютором (многоходовой) | message, history[] |

## Методология обучения (QLoRA)

Дообучение модели проводится по методу QLoRA (Quantized Low-Rank Adaptation), который позволяет эффективно адаптировать большие языковые модели при ограниченных ресурсах графического процессора:

- **4-битное квантование (NF4)** — базовая модель загружается в 4-битном формате, что снижает потребление видеопамяти с ~48 ГБ до ~14 ГБ
- **LoRA-адаптеры (ранг r = 4–32)** — обучаются только низкоранговые матрицы дополнения по 7 модулям (q_proj, k_proj, v_proj, o_proj, gate_proj, up_proj, down_proj), что составляет ~0,5–1 % от всех параметров модели
- **LoRA alpha = 8–64** — масштабирование адаптеров в зависимости от режима обучения
- **Двойное квантование** — дополнительное сжатие квантованных констант (bfloat16 compute dtype) для экономии памяти
- **Контекстная длина** — инференс: 8 192 токена; обучение: до 2 048 токенов
- **Трехэтапная стратегия** — отладка (1 эпоха, 10 шагов, r=4) → облегченная (2 эпохи, r=8) → полная (3 эпохи, r=32)

## Ключевые возможности

### Генерация учебного контента

На основе текста лекции система автоматически создает:

- **Структурированные конспекты** — ключевые тезисы, термины и определения в маркированном формате
- **Тесты для самопроверки** — вопросы с 4 вариантами ответов (A/B/C/D), 3 уровня сложности
- **Пояснения по запросу** — подробная расшифровка терминов и понятий из лекции
- **Диалоговый режим** — многоходовой диалог для углубленного изучения темы

### Интеграция с Moodle (ЭОС)

- Единая точка входа для студентов и преподавателей
- Отправка текста лекции ИИ-тьютору и получение результата
- Отслеживание активности использования
- Единый интерфейс без необходимости обучения работе с новыми инструментами

### Поддержка инклюзивного образования

- Настраиваемый размер шрифта и интерфейс
- Альтернативные форматы вывода (текст, структурированный конспект)
- Возможность многократного обращения за пояснениями без ограничений
- Индивидуальный темп изучения материала

## Признание проекта

Разработка Сальского индустриального техникума участвует в Международной университетской премии в области искусственного интеллекта и больших данных **«Гравитация»** в специальной номинации **«Лучшее отраслевое решение»** от платформы Qubu. Это подтверждает высокий потенциал проекта для тиражирования в системе среднего профессионального образования России.

Проект реализуется силами команды техникума без привлечения сторонних разработчиков. В дальнейшем наработки будут открыты для других учреждений СПО под свободной лицензией.
