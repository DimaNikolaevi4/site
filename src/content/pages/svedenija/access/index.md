## Условия для обучения лиц с ОВЗ и инвалидов

ГБПОУ РО «Сальский индустриальный техникум» создаёт специальные условия для получения образования обучающимися с ограниченными возможностями здоровья (ОВЗ) и инвалидами в соответствии с требованиями:

- Федерального закона от 29.12.2012 № 273-ФЗ «Об образовании в Российской Федерации» (ст. 79)
- Федерального закона от 24.11.1995 № 181-ФЗ «О социальной защите инвалидов в Российской Федерации»
- Приказа Министерства образования и науки РФ от 09.11.2015 № 1309 (требования доступности)
- Приказа Рособрнадзора № 1493 (раздел 2.11)

---

## Архитектурная доступность

### Корпус №1 (ул. Ленина, 27)

| Элемент доступности | Наличие |
|--------------------|---------|
| Пандус при главном входе | ✅ Есть |
| Поручни на лестницах | ✅ Есть |
| Широкие дверные проёмы (≥ 90 см) | ✅ Есть |
| Адаптированный санитарный узел | ✅ Есть |
| Тактильные напольные указатели | ✅ Есть |
| Кнопка вызова сотрудника | ✅ Есть |
| Лифт | ❌ Нет (здание одноэтажное) |
| Парковочные места для инвалидов | ✅ Есть (2 места) |

### Корпус №2

| Элемент доступности | Наличие |
|--------------------|---------|
| Пандус при входе | ✅ Есть |
| Поручни | ✅ Есть |
| Адаптированный санитарный узел | ✅ Есть |

---

## Информационная доступность

- Сайт техникума соответствует требованиям ГОСТ Р 52872-2019 (доступность для слабовидящих)
- Версия сайта для слабовидящих: увеличенный шрифт, высокая контрастность, отключение анимаций
- Информационные стенды с тактильными элементами в корпусах
- Тифлотехнические средства в библиотеке

---

## Психолого-педагогическое сопровождение

Для обучающихся с ОВЗ обеспечивается:
- Индивидуальные программы адаптации образовательного процесса
- Работа педагога-психолога (консультации по расписанию)
- Тьюторское сопровождение (при необходимости)
- Адаптированные образовательные программы по запросу

---

## Специальные условия при прохождении аттестации

Для обучающихся с ОВЗ на период аттестации предусмотрено:
- Увеличение продолжительности выполнения заданий
- Возможность использования технических средств
- Присутствие ассистента при необходимости

---

## Общежитие для лиц с ОВЗ

В общежитии техникума предусмотрены:
- Комнаты, адаптированные для лиц с нарушениями опорно-двигательного аппарата
- Адаптированный санитарный узел
- Бесплатное проживание для детей-сирот и детей, оставшихся без попечения родителей
