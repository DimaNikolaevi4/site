# 8.1. Информационно-образовательные ресурсы

Подборка официальных информационно-образовательных ресурсов для обучающихся, преподавателей и родителей ГБПОУ РО «Сальский индустриальный техникум».

## Электронная информационно-образовательная среда техникума (ЭИОС)

Расписание занятий, учебные материалы, текущие оценки, сведения о посещаемости и индивидуальная коммуникация с преподавателями осуществляются в Электронной информационно-образовательной среде:

<a href="https://эос.сит-сальск.рф/" class="btn btn-primary" target="_blank" rel="noopener noreferrer">
  <i class="bi bi-mortarboard-fill" aria-hidden="true"></i> Перейти в ЭОС
</a>

Документы об ЭИОС:

- Положение об ЭИОС, каталог электронных образовательных ресурсов и перечни ЭОР по программам — см. раздел [Материально-техническое обеспечение → ЭОР](/svedenija/objects/#п-279-эор)
## Цифровая (электронная) библиотека

Доступ к ЭБС «Юрайт» и «Лань» для студентов и преподавателей техникума: лицензионные договоры, инструкции по регистрации, мобильное приложение «Лань», каталог ЭОР по специальностям 09.02.01, 38.02.01, 08.01.07, 13.01.10, 15.01.05, 15.02.07, 38.01.02, 43.01.09.

- Полный комплект документов и инструкций — на странице [«Библиотека техникума»](/studentam-i-roditeljam/biblioteka/)
