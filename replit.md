# ГБПОУ РО «Сальский индустриальный техникум» — сайт

## Overview

This project is a static website for the Salsk Industrial Technical College, built with Eleventy (11ty) and managed with Markdown content and Decap CMS. The site is hosted on Beget, with its remote repository on GitHub. The primary goal is to provide an easily maintainable and performant online presence for the college, showcasing its offerings, news, and essential information.

## User Preferences

- **Pushing to GitHub:** The user manually pushes changes to GitHub via the Replit Git panel. Automated pushes from the agent are not possible due to GitHub authentication limitations. If automated pushing is required, a Personal Access Token or GitHub integration setup will be necessary.
- **Rolling back to a commit:** The user performs rollbacks manually in the Shell. The agent should be aware that destructive git operations are blocked. The process involves `git fetch origin --unshallow`, `git reset --hard <sha>`, and `npm install`. After a rollback, the user will request the agent to restart the "Start application" workflow.
- **Communication style:** The user expects clear and concise instructions, especially for manual Git operations.
- **Workflow preferences:** The user prefers to manage Git pushes and rollbacks directly. The agent should provide guidance for these tasks when requested.
- **No changes to `src/assets/vendor/php-email-form/validate.js`** as it's a custom script with no npm equivalent.

## System Architecture

The website is a static site generated by Eleventy.

### UI/UX Decisions

- **Global styling:** All sections (`<section>` or `.section`) have a default white background, which needs to be explicitly set to `transparent` if the decorative SVG background of the site should remain visible.
- **Design consistency:** A canonical Type B design (v3.5, April 2026) is established for section pages, with `/abiturientam/` serving as the standard.
- **Component rendering:** Components included from Markdown files must generate HTML as a single, continuous string without empty lines or line breaks between block-level tags to prevent unwanted `<p>` wrapping by `markdown-it`. Nunjucks whitespace control (`{%- ... -%}`, `{{- ... -}}`) is mandatory for such components.
- **Navigation blocks:** Canonical navigation blocks within page bodies (e.g., "Подразделы", "Структура раздела") are rendered using the `component-news--razdel` grid, disallowing simple bulleted lists. Final CTAs on long section pages are also implemented as a two-card grid.

### Technical Implementations

- **Eleventy:** Used for static site generation.
- **Nunjucks:** Templating engine for Eleventy.
- **Markdown:** Content authoring.
- **Decap CMS:** Content management.
- **Vendor libraries:** Frontend libraries like Bootstrap, AOS, Swiper, etc., are managed as npm packages and copied by Eleventy from `node_modules/` to `public/assets/mentor/vendor/`.
- **Project Structure:**
    - `src/`: Source files including Nunjucks templates, content, and rubric configurations.
    - `public/`: The built static site.
    - `.eleventy.js`: Eleventy configuration.
- **Page Layouts:**
    - `layouts/post.njk`: For news and article-type content (Type C).
    - `layouts/page.njk`: For general section pages (Type B).
    - `layouts/page-full.njk`: Extended Type B for canonical sections, incorporating a two-column layout with a sticky sidebar.
    - `layouts/svedenija-page.njk`: Specific layout for the "Сведения" section, managing left-hand navigation.
- **Frontmatter:** Extensive use of frontmatter fields for controlling page layouts, content display, and navigation. Key fields include `layout`, `permalink`, `title`, `description`, `image`, `hero` configuration, `breadcrumbs`, `emoji`, `category`, `attachments`, `relatedPages`, `suppressSubrubrics`, and specific fields for the "Сведения" section.
