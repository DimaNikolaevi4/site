## 📁 ДИРЕКТОРИЯ /public (АРТЕФАКТ)

Согласно STRUCTURE_AND_PRINCIPLES.md, директория `/public` является **артефактом** и содержит:

```
public/
├── content/           # Старая структура контента (НЕ ИСПОЛЬЗУЕТСЯ)
│   ├── categories/    # Категории для Eleventy
│   ├── news/          # Новости
│   ├── documents/     # Документы
│   └── pages/         # Страницы
├── svedenija/         # Копия раздела "Сведения"
├── assets/            # Ресурсы
├── images/            # Изображения
└── index.html         # Главная страница (билд)
```

### Зачем нужна директория /public:
1. **Результат сборки Eleventy** — сюда генерируется финальный сайт при `npm run build`
2. **Deployment-ready** — содержимое готово к выгрузке на хостинг
3. **НЕ редактируется вручную** — все изменения вносятся в `/src` и `/mirror`
