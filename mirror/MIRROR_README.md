# Назначение директории /mirror

## 🎯 Основное назначение

Директория `/mirror` — это **зеркало официальной структуры сайта** ГБПОУ РО «Сальский индустриальный техникум» (https://sit-salsk.ru/), организованное в соответствии с:

1. **Приказом Рособрнадзора №1493** от 02.09.2021 «Об утверждении требований к структуре официального сайта образовательной организации»
2. **Рубрикатором сайта** — раздел «Выберите нужный раздел/рубрику сайта» на главной странице https://sit-salsk.ru/

---

## 📁 Структура директории

```
mirror/
├── {N}_{SECTION}/              # Основные разделы (10 шт.)
│   ├── index.html              # Главная страница раздела
│   ├── {N.N}_{SUBSECTION}/     # Подразделы уровня 1
│   │   └── index.html          # Страница подраздела
│   └── {N.N.N}_{SUBSUBSECTION}/# Подразделы уровня 2
│       └── index.html          # Страница подраздела
├── unsorted/                   # Технические файлы (несортированные)
└── SITE_RUBRICS_STRUCTURE.md   # Документация структуры рубрик
```

## 🔗 Взаимосвязь с другими директориями

### /src
- **Назначение**: Исходный код сайта (Eleventy SSG)
- **Связь**: Контент из `/mirror` может быть использован для создания шаблонов в `/src`

### /public
- **Назначение**: Результат сборки (`npm run build`)
- **Статус**: **АРТЕФАКТ**, не редактируется вручную
- **Связь**: Генерируется автоматически из `/src`

### /mirror vs /public/content
- `/mirror` — исходное зеркало для анализа и импорта
- `/public/content` — устаревшая структура, подлежит миграции

## 📋 Для чего используется

1. **Анализ структуры оригинального сайта**
   - Понимание иерархии разделов
   - Выявление отсутствующего контента

2. **Миграция контента**
   - Перенос материалов в новую CMS
   - Сохранение истории изменений

3. **Соответствие требованиям**
   - Проверка полноты обязательных разделов
   - Подготовка к проверкам Рособрнадзора

4. **Резервное копирование**
   - Локальная копия критически важных страниц
   - Быстрый доступ к информации без интернета

---

## ⚠️ Важные замечания

1. **Не редактировать вручную** файлы в `/mirror` — это прямое зеркало сайта
2. Для внесения изменений использовать `/src` и систему сборки Eleventy
3. При обновлении контента на sit-salsk.ru требуется актуализация соответствующих файлов
4. Файлы `.gitkeep` в папках нужны для отслеживания пустых директорий в Git
