## 🎯 Промт: «Интегрировать готовую адаптивную шапку сайта в проект Eleventy + Bootstrap 5»

### Контекст
У нас есть статический сайт на генераторе **Eleventy** (11ty), шаблонизатор **Nunjucks**, стили на **Bootstrap 5 + SCSS**, клиентский поиск **Lunr.js**, редактор **Decap CMS**.  
Проект развёрнут локально, структура соответствует описанию в файле `README.md`.  
Требуется заменить существующую шапку (header) на новую, код которой прилагается ниже. Новая шапка должна быть **адаптивной**, соответствовать требованиям доступности (WCAG), поддерживать «Версию для слабовидящих», содержать рубрикатор (select), ссылки на ЭОС, телефоны, иконки соцсетей, поиск и т.д.

### Исходный код новой шапки (HTML/CSS/JS)
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0, maximum-scale=5.0">
  <title>Шапка сайта ГБПОУ РО «СИТ»</title>
  <!-- Bootstrap 5 + Icons (уже есть в проекте, не дублировать) -->
  <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.13.0/font/bootstrap-icons.min.css">
  <style>
    /* Стили шапки — их нужно перенести в SCSS-файлы проекта */
    :root {
      --sit-primary: #0d4a6b;
      --sit-accent: #e67e22;
      --sit-accent-hover: #d35400;
      --sit-border: #dee2e6;
      --focus-outline: 0.125rem solid #0d4a6b;
    }
    /* ... (полный CSS из предоставленного кода) ... */
  </style>
</head>
<body>
  <!-- вся разметка шапки с классами, логотипами, меню, панелями -->
</body>
</html>
```

### Задача
1. **Перенести разметку шапки** в Nunjucks-партиал `src/_includes/partials/header.njk` (или аналогичный).  
2. **Разбить на логические части** (при необходимости):  
   - `header-top` (логотип, герб, название)  
   - `header-nav` (навигационное меню)  
   - `header-info-bar` (график, телефоны, ЭОС, иконки) — сделать две версии: десктопную (видна на `md` и выше) и мобильную (видна на `<md`).  
   - `header-actions-panel` (рубрикатор + ссылка «Контакты»).  
3. **Адаптировать стили под существующую архитектуру SCSS**:  
   - Создать файл `src/assets/scss/components/_header.scss`.  
   - Импортировать его в главный `styles.scss`.  
   - Заменить все `px` на `rem` (уже сделано в предоставленном CSS, но проверить).  
   - Учесть, что Bootstrap 5 уже подключён — не дублировать его.  
   - Сохранить все медиа-запросы (адаптивность).  
4. **Перенести JavaScript-логику** в отдельный файл `src/assets/js/header.js` и подключить через `eleventy.config.js` или добавить в глобальный скрипт.  
   - Логика рубрикатора (select → переход по ссылке).  
   - Логика «Версия для слабовидящих» (переключение классов `a11y-high-contrast`, `a11y-large-font`, `a11y-no-animation` с сохранением в `localStorage`).  
   - Закрытие мобильного меню после клика по ссылке.  
   - Синхронизация двух кнопок слабовидящих (десктопной и мобильной).  
5. **Интеграция с динамическими данными Eleventy**:  
   - Ссылки меню (пункты: Главная, Сведения об образовательной организации, Абитуриентам, Студентам, Учебная работа, Воспитание, Безопасность) должны браться из `src/_data/menu.yaml` или аналогичного файла, чтобы меню было централизованно управляемым.  
   - Рубрикатор (select) – его опции тоже должны генерироваться из данных (например, `src/_data/rubrics.yaml`).  
   - Ссылки на ЭОС, телефоны, email, VK – вынести в `src/_data/contacts.yaml`.  
6. **Изображения** (логотип `logo.png`, герб `gerb-red1.png`) – разместить в `src/assets/images/`, поправить пути на `{% static 'images/logo.png' %}` или относительные `/assets/images/logo.png`.  
7. **Модальное окно поиска** – должно работать через Bootstrap Modal, но поисковую форму связать с существующим Lunr.js (если он уже реализован). Временно можно оставить демо-обработку, но с комментарием «TODO: подключить Lunr».  
8. **Совместимость** – новая шапка не должна ломать существующие страницы, подвал и другие компоненты.  
9. **Проверить соответствие нормам**:  
   - Версия для слабовидящих (клавиатурная навигация, контраст, крупный шрифт).  
   - Alt-тексты у всех изображений.  
   - Семантическая разметка (`<header>`, `<nav>`, `<select>` с `aria-label` и т.д.).  

### Требования к реализации
- Использовать существующие глобальные переменные Eleventy (`site.url`, `site.title` и т.п.) из `_data/site.yaml`.  
- Не удалять и не перезаписывать существующие глобальные скрипты, а дополнить их.  
- Для иконок использовать Bootstrap Icons (они уже подключены).  
- Убедиться, что на мобильных устройствах меню раскрывается и работает без горизонтального скролла.  
- После интеграции шапка должна отображаться на **всех страницах** сайта (через `{% include "partials/header.njk" %}` в базовом шаблоне `base.njk`).  

### Формат ответа от Coder QA
Ожидается:  
- Краткое описание внесённых изменений.  
- Список созданных/изменённых файлов.  
- Инструкция по проверке (локальный запуск `npm run dev`).  
- Весь код новых файлов (header.njk, _header.scss, header.js, обновлённые data-файлы).  

### Примечание
В проекте уже есть Bootstrap 5 и jQuery не используется. Новая шапка не должна добавлять лишних зависимостей.  
Если какой-то элемент (например, Lunr.js) ещё не реализован – оставить заглушку с комментарием.
