Открывается по клику на соответствующую кнопку (иконка «сетка» или «бургер»). Внутри неё — иерархическое дерево рубрик с аккуратными отступами.

•	Тело панели: рекурсивно сгенерированный список на основе rubrics.main_rubrics.
•	Никакого JavaScript для раскрытия подуровней — они видны сразу (как на оригинальном сайте sit-salsk.ru). Это максимально просто и надёжно.
•	Стилизация: минимальная, используем классы Bootstrap (list-unstyled, ms-3 для отступов, fw-bold для заголовков разделов).
4. Мобильная версия
Кнопка-гамбургер (уже есть в Mentor) открывает ту же самую offcanvas-панель. Это обеспечивает единообразие и экономит код.
5. Визуальная интеграция с Mentor
Offcanvas будет стилизован под общий дизайн (цвета, шрифты) через несколько строк CSS в main.css. Никаких конфликтов, так как это стандартный компонент Bootstrap 5.
