# Инструкция по деплою на Beget

## ⚠️ Важно: Директория /mirror

Директория `/mirror` содержит точную копию структуры оригинального сайта `sit-salsk.ru` и используется как **источник информации** при разработке.

- ✅ `/mirror` **остаётся в репозитории** для доступа к исходной структуре
- ❌ `/mirror` **НЕ должна загружаться** на хостинг Beget при деплое
- 📦 В `.gitignore` добавлено правило `/mirror/`, чтобы исключить директорию из деплоя

**При подготовке файлов для загрузки:**
- Используйте только содержимое папки `public/` (результат сборки `npm run build`)
- Убедитесь, что директория `/mirror` не включена в архив для загрузки
- Скрипт деплоя должен игнорировать эту директорию

## Шаг 3: Подготовка директории на хостинге

```bash
# Перейти в директорию домена
cd ~/sit-saljsk.rf/

# Очистить public_html (если там есть старые файлы)
rm -rf public_html/*

# Убедиться, что папка существует
mkdir -p public_html
```

---

## Шаг 4: Загрузка файлов на сервер

### Вариант A: Через SCP (рекомендуется)

Из локальной терминала:

```bash
# Загрузить архив
scp deploy-package.tar.gz <ваш_логин>@beget.com:~/sit-saljsk.rf/

# Подключиться по SSH
ssh <ваш_логин>@beget.com

# Распаковать в public_html
cd ~/sit-saljsk.rf/
tar -xzf deploy-package.tar.gz -C public_html/ --strip-components=1

# Удалить архив
rm deploy-package.tar.gz
```

### Вариант B: Через SFTP/FileZilla

1. Подключиться к `sftp.beget.com` с вашим логином/паролем
2. Загрузить содержимое папки `public/` в `~/sit-saljsk.rf/public_html/`
3. Убедиться, что `submit-form.php` загружен в корень `public_html/`

## Шаг 5: Настройка прав доступа

```bash
cd ~/sit-saljsk.rf/public_html/

# Права на файлы
chmod 644 *.html *.php .htaccess

# Права на папки
chmod 755 assets/ content/ about/ contacts/ documents/ svedenija/ admin/ robots/ thank-you/

# Папка для загрузок формы (должна быть доступна для записи)
mkdir -p uploads/forms
chmod 777 uploads/forms
```

---

## Шаг 6: Настройка Node.js в панели Beget (если требуется)

1. Зайти в панель управления Beget → Сайты → sit-saljsk.rf
2. Раздел "Node.js" (если есть)
3. Выбрать версию Node.js 18+
4. Сохранить

*Примечание: Для статического сайта Node.js на сервере не требуется, только PHP для формы.*

## Поддержка после деплоя

### Обновление контента:
1. Внести изменения в исходники (`src/`)
2. Выполнить `npm run build`
3. Загрузить изменённые файлы из `public/` на сервер

### Логи формы:
- Файл логов: `~/sit-saljsk.rf/public_html/forms.log`
- Загруженные файлы: `~/sit-saljsk.rf/public_html/uploads/forms/`
