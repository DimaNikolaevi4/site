# ✅ Минимальная сборка сайта готова

## 📦 Что создано

### 1. Структура файлов
```
/workspace/
├── .eleventy.js              # Конфигурация Eleventy
├── package.json              # Зависимости и скрипты
├── README.md                 # Документация
└── src/
    ├── _data/
    │   └── site.yaml         # Глобальные данные сайта
    ├── _filters/
    │   ├── dateRu.js         # Фильтр даты (русский)
    │   ├── truncate.js       # Фильтр обрезки текста
    │   └── slugify.js        # Фильтр транслитерации
    ├── _includes/
    │   ├── components/
    │   │   ├── header.njk    # Шапка сайта
    │   │   └── footer.njk    # Подвал сайта
    │   └── layouts/
    │       └── base.njk      # Базовый layout
    ├── content/
    │   └── news/
    │       └── example.md    # Пример новости
    ├── pages/
    │   ├── index.md          # Главная страница
    │   ├── news-list.njk     # Список новостей
    │   ├── news-post.njk     # Страница новости
    │   ├── rubric-lists/
    │   │   └── default.njk   # Список материалов
    │   ├── materials/
    │   │   └── detail.njk    # Страница материала
    │   ├── static.njk        # Статическая страница
    │   ├── search.njk        # Поиск
    │   └── 404.njk           # Страница ошибки
    └── styles/
        └── main.css          # Основные стили
```

### 2. Типы страниц (6 основных)

| № | Тип | Файл | Описание |
|---|-----|------|----------|
| 1 | **Главная** | `src/pages/index.md` | Герой-блок, преимущества, превью новостей, CTA |
| 2 | **Список новостей** | `src/pages/news-list.njk` | Пагинация, карточки новостей |
| 3 | **Страница новости** | `src/pages/news-post.njk` | Полный текст, метаданные, другие новости |
| 4 | **Список материалов** | `src/pages/rubric-lists/default.njk` | Фильтры, сайдбар, пагинация |
| 5 | **Страница материала** | `src/pages/materials/detail.njk` | Контент, оглавление, теги, навигация |
| 6 | **Статическая страница** | `src/pages/static.njk` | Текст, контакты, руководство |
| 7 | **Поиск** | `src/pages/search.njk` | Форма, результаты, советы |
| 8 | **404** | `src/pages/404.njk` | Сообщение об ошибке, ссылки |

### 3. Компоненты

- **Header** - адаптивная шапка с навигацией
- **Footer** - подвал с контактами и ссылками
- **Base Layout** - общая обертка для всех страниц

### 4. Стили (CSS)

- Mobile First подход
- CSS переменные для легкой кастомизации
- Адаптивная сетка (Grid/Flexbox)
- БЭМ-подобный нейминг
- Базовая доступность (WCAG)

## 🚀 Как использовать

### На локальном компьютере:

1. **Скопируйте файлы**
   ```bash
   # Скопируйте всю папку проекта или отдельные файлы
   ```

2. **Установите зависимости**
   ```bash
   npm install
   ```

3. **Запустите сервер разработки**
   ```bash
   npm run dev
   ```
   Откройте http://localhost:5000

4. **Редактируйте стили**
   - Откройте `src/styles/main.css`
   - Измените цвета в `:root`
   - Настройте шрифты и отступы

5. **Добавьте контент**
   - Обновите `src/_data/site.yaml`
   - Создайте новости в `src/content/news/`
   - Добавьте изображения в `src/assets/images/`

6. **Соберите для продакшена**
   ```bash
   npm run build
   ```
   Результат в папке `public/`

## 🎨 Что настраивать в первую очередь

1. **Цвета и шрифты** → `src/styles/main.css`
2. **Данные сайта** → `src/_data/site.yaml`
3. **Логотип** → замените в `src/_includes/components/header.njk`
4. **Меню навигации** → отредактируйте `src/_includes/components/header.njk`
5. **Подвал** → обновите контакты в `src/_includes/components/footer.njk`

## 📝 Примечания

- Сборка минимальна и содержит только базовые компоненты
- JavaScript для интерактивности (мобильное меню, поиск) нужно добавить отдельно
- Для полноценного поиска требуется настройка Lunr.js
- Пагинация работает на основе встроенных возможностей Eleventy

## 🔗 Следующие шаги

После локальной настройки и тестирования:
1. Загрузите обновленные файлы в репозиторий
2. Настройте CI/CD для автоматической сборки
3. Разверните на хостинге (Beget)
4. Подключите Decap CMS для управления контентом
