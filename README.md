# Минимальная сборка сайта техникума

Это стартовый шаблон для сайта ГБПОУ РО "Сальский индустриальный техникум" на базе Eleventy.

## 📁 Структура проекта

```
src/
├── _data/              # Глобальные данные (site.yaml)
├── _filters/           # Пользовательские фильтры Nunjucks
├── _includes/          # Шаблоны и компоненты
│   ├── components/     # Header, Footer
│   ├── layouts/        # Базовый layout
│   └── sections/       # Секции страниц
├── assets/             # Статические файлы (изображения, JS)
├── content/            # Контент (новости, материалы)
│   └── news/           # Новости
├── pages/              # Шаблоны страниц
│   ├── materials/      # Страница материала
│   ├── rubric-lists/   # Список материалов
│   └── index.md        # Главная страница
└── styles/             # CSS стили
```

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Сайт будет доступен по адресу: http://localhost:5000

### 3. Сборка для продакшена
```bash
npm run build
```
Результат сборки появится в папке `public/`

## 📄 Типы страниц

В сборке представлены 6 основных типов страниц:

1. **Главная** (`src/pages/index.md`) - герой-блок, преимущества, новости, CTA
2. **Список материалов** (`src/pages/rubric-lists/default.njk`) - каталог с фильтрами и пагинацией
3. **Страница материала** (`src/pages/materials/detail.njk`) - подробный контент с сайдбаром
4. **Статическая страница** (`src/pages/static.njk`) - информация о техникуме
5. **Поиск** (`src/pages/search.njk`) - форма и результаты поиска
6. **404** (`src/pages/404.njk`) - страница ошибки

## 🎨 Стилизация

Все стили находятся в `src/styles/main.css`. Основные принципы:

- **Mobile First** - базовые стили для мобильных, затем media queries
- **CSS Variables** - легкая кастомизация цветов и отступов
- **БЭМ-подобный нейминг** - понятная структура классов
- **Доступность** - учтены требования WCAG 2.1 AA

## ⚙️ Конфигурация

Основной конфиг Eleventy: `.eleventy.js`

Ключевые настройки:
- Входная директория: `src/`
- Выходная директория: `public/`
- Шаблоны: Nunjucks (.njk) + Markdown (.md)
- Поддержка YAML для данных

## 📝 Следующие шаги

После копирования на локальный компьютер:

1. Настройте цвета и шрифты в `src/styles/main.css`
2. Добавьте логотип и изображения в `src/assets/images/`
3. Обновите данные сайта в `src/_data/site.yaml`
4. Создайте реальные новости в `src/content/news/`
5. Настройте мобильное меню (JavaScript)
6. Добавьте интерактивность (поиск, фильтры)
